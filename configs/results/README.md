# Results Directory

This directory contains genuine outputs from actual experiment execution.

## Files

| File | Description |
|------|-------------|
| `baseline_results.jsonl` | Full outputs from frozen LLM baseline (one JSON per topic) |
| `baseline_summary.csv` | Per-topic CAR scores — baseline condition |
| `rag_results.jsonl` | Full outputs from RAG-enhanced condition |
| `rag_summary.csv` | Per-topic CAR scores — RAG condition |
| `statistics.txt` | Wilcoxon test results for post-cutoff bin |
| `figures/car_barplot.png` | Grouped bar chart: CAR by temporal bin |
| `figures/car_degradation.png` | Line plot: CAR degradation with temporal distance |

## Important

All files in this directory are generated by running:
```bash
python scripts/evaluate_baseline.py --config configs/experiment_blueprint.yaml
python scripts/evaluate_rag.py --config configs/experiment_blueprint.yaml
python scripts/plot_results.py --results_dir results/
```

**No results are manually created or fabricated.**
